# Machine Learning Engineer (NLP)

**Company:** Northwind Analytics
**Location:** Bengaluru, India (Hybrid)
**Type:** Full-time

## About the Role

We are hiring a Machine Learning Engineer to build and ship NLP systems that
power our document intelligence platform. You will own models end to end: from
data preparation and fine-tuning through deployment, monitoring and iteration.
This is a hands-on engineering role, not a research role -- most of your week
is writing production Python.

## Responsibilities

- Design, train and evaluate NLP models for classification, extraction and retrieval
- Build retrieval-augmented generation pipelines over customer document sets
- Deploy models as containerised services and monitor them in production
- Write clean, tested Python and participate in code review
- Partner with product and backend engineers to ship features

## Required Qualifications

- 3+ years of professional experience in machine learning or data science
- Strong Python, including production code (not just notebooks)
- Hands-on experience with PyTorch and the Transformers ecosystem
- Practical NLP experience: text classification, NER, embeddings or retrieval
- Working knowledge of SQL for data extraction and analysis
- Experience with Docker and deploying models behind a REST API
- Comfortable with Git and collaborative development workflows
- Bachelor's degree in Computer Science, Engineering, Statistics or a related field

## Preferred Qualifications

- Experience with vector databases and RAG architectures
- Familiarity with MLOps tooling for experiment tracking and model monitoring
- Cloud deployment experience on AWS
- Exposure to Kubernetes for orchestration
- Experience with Spark or distributed data processing
- Master's degree in a quantitative field

## What We Offer

Competitive compensation, hybrid working, and a small team where your work
ships to real users within weeks.
